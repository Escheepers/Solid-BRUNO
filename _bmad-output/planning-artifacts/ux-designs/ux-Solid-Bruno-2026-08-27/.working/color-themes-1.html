Bruno Vehicle Hire — Color Theme Variations (Round 1)

Six candidate palettes for the internal, staff-only back-office app (Vehicles / Customers / Bookings, compact table density). Each variation shows its full semantic token set and a realistic Bookings row rendering — including a booking-overlap error state, since conflict and delete-guard messaging is a core interaction — in both light and dark mode.
